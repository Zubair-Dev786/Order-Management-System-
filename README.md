# Orderly

A simple order management application built with HTML, CSS, and JavaScript.

## Features

* Add customer orders
* Track pending and received orders
* Manage advance and pending payments
* Edit and delete orders
* Data persistence using LocalStorage

## Technologies

* HTML
* CSS
* JavaScript
* LocalStorage
